# 中文学术写作规范

## 参考文献：GB/T 7714-2015

两种制式，先用者择一，全文不得混用：

- **顺序编码制**：按正文引用先后编号，方括号上标如 `[1]`。同一处引用多篇用逗号 `[1,3]`，连续序号用短横线 `[1-3]`。**同一文献被多次引用时，正文标首次序号，页码写在方括号外**。
- **著者-出版年制**：圆括号夹注。欧美多著者只标第一著者姓 + `et al.`，中国著者用 `等`。同年多篇加 `a,b,c` 区分。页码置于括号外。

**文献类型标识**：`[M]` 专著 · `[J]` 期刊 · `[D]` 学位论文 · `[C]` 论文集 · `[P]` 专利 · `/OL` 联机载体。电子资源须加引用日期、访问途径与 DOI。

示例：

```
[1] 哈里森, 沃尔德伦. 经济数学与金融数学[M]. 谢远涛, 译. 北京: 中国人民大学出版社, 2012: 235-236.
[2] 袁训来, 陈哲, 肖书海, 等. 蓝田生物群: 一个认识多细胞生物起源和早期演化的新窗口[J]. 科学通报, 2012, 55(34): 3219.
```

BibTeX 用 `gbt7714-numerical` 或 `gbt7714-author-year` 样式；中文作者之间用 `and` 连接，`et al.` 由样式渲染为 `等`。

> **版本陷阱**：不少院校的旧版规范仍沿用 GB 7714-87 的简化写法（三人以上只列三人加"等"），与 GB/T 7714-2015 不一致。**一律以目标单位或期刊的最新《投稿须知》为准**，并在动手前确认。

## 学位论文结构

前置部分：封面 → 原创性声明与版权授权书 → 中文摘要与关键词 → 英文摘要与关键词 → 目录 → 图表索引 → 符号表。
正文部分：绪论 → 相关工作/文献综述 → 方法/理论/系统设计 → 实验与结果/案例分析 → 结论与展望。
后置部分：参考文献 → 附录 → 致谢 → 攻读学位期间成果。

要点：

- **页码分制**：前置部分用罗马数字，正文用阿拉伯数字。
- **绪论必含**：学术背景与理论/实际意义、**国内外文献综述**、课题来源与主要研究内容。
- **结论单独成章但不加章号**，需点明创造性成果/创新点、应用前景与后续展望。
- **摘要**：理工科按"目的—方法—结果—结论"四要素组织；不出现公式、图表、引用编号；不写成目录式罗列。博士摘要字数通常显著多于硕士（各校差异大，以本校模板为准）。
- **关键词** 3–8 个，按外延层次排列（外延大的在前）。
- **英文摘要须与中文摘要信息对等**，不得增删核心结论。
- **图表**：图题在图**下**，表题在表**上**；表格用**三线表**（上下粗实线、中间细实线，不加左右边线），表头尽量不用斜线；引用他人图表须注明出处。
- 参考文献数量要求各校差异极大（常见：博士 ≥100 篇含外文 ≥30，硕士 ≥40 篇含外文 ≥10），**以本校规定为准**。

## 开题报告

典型六个部分：题目 → 立题依据 → 研究内容及预期目标 → 研究方案 → 进度安排 → 参考文献。

- **题目**：研究对象 + 研究内容 + 要解决的问题，一般不超过 20 字，必要时加副标题。
- **立题依据**含两部分：目的与意义；**文献综述**——须有作者本人的分析归纳，并明确指出选题的位置、优势与可能的突破点，不能只是罗列。
- **进度安排**：分阶段、起止明确、阶段之间不断档。
- **参考文献**必须有本人亲自阅读；**不得转录他人文后文献**。

## 查重

- 各校阈值差异大，常见量级：本科 ≤30%（重点院校 ≤20%）；硕士 ≤15%（部分 ≤10%）；博士 ≤5%–8%。部分院校对文献综述等单章另设上限。
- 覆盖范围通常包括摘要、正文（含引用）、致谢、附录；封面、目录、参考文献表是否计入需确认。
- **跨语言翻译法已被识别**：把中文译成英文再译回，不能规避查重。真正有效的是重组结构与深化分析，而不是同义词替换。
- 只用正规渠道查重，避免无资质平台导致稿件泄露。

## 中文改学术英文：五个真正的陷阱

润色改不掉下面这些，因为它们不是句子问题而是结构问题。

1. **信息密度与推进方式**。中文偏宏观铺垫、层层递进；英文学术写作要求把贡献**前置**。逐句翻译会保留中文的铺垫式推进，无论怎么润色都读起来"绕"。
2. **句法负担**。英文必须显性表达逻辑，中文的从句/状语堆叠照搬过去会淹没主干。让主句承担核心信息，必要时拆句。
3. **动词搭配**（最暴露翻译痕迹的一类）：
   - ✗ `do a research` / `make an experiment` / `solve the question`
   - ✓ `conduct a study` / `run an experiment` / `address a question` / `pose a hypothesis` / `provide evidence`
4. **讨论深度不足**。只写 "our results showed that X increased" 停留在描述层。Discussion 至少完成四件事：解释结果、与文献比较、说明意义、承认局限。用 `suggest / indicate / may be explained by` 承担推断。
5. **写作路径**。先写中文再逐句翻译，结构仍然是中文的。**直接用英文构建段落核心句**，再补细节。

**术语一致性**：同一概念全文只用一种译法；缩写首次出现给全称；中文术语与英文对应关系固定下来，不要中途漂移——同义词替换在术语层面会变成事实性错误（这也是 "tortured phrases" 的由来，例如把 artificial intelligence 换成 counterfeit consciousness）。

## 与工具配合的注意事项

- **知网（CNKI）没有开放 API**。`ref_verify` 覆盖不了中文文献。让用户导出 RIS / NoteExpress / NoteFirst 题录，能核验的核验，不能的标 `unverified-cnki`。**不要声称搜过知网。**
- GB/T 7714 格式的参考文献，`ref_verify` / `bib_check` 仍可核验其**存在性与英文元数据**；中文题名在 OpenAlex / Crossref 中的覆盖率参差不齐，`not_found` 不等于伪造，需人工判断。
- 中文学位论文排版通常需要 `ctex`（`ctexbook` / `ctexart`）与 `gbt7714` 宏包；编译用 XeLaTeX 而非 pdfLaTeX。
